Publish and backup

This website does not have a server or an account system. Your edits stay in this browser until you download the updated site data.

  1. Save your writing and screenshots using the editor.
  2. Click Download updated site-data.js below.
  3. In your GitHub Pages repository, replace the existing site-data.js with the downloaded file and commit the change.
  4. The published website will then show your writing to anyone with the link.

Restore a backup

You can import a previously downloaded site-data.js. This will replace the drafts in this browser.

Go back to the published version

If you've made unwanted local edits, you can discard them and reload what is in site-data.js.
